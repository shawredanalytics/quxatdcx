# QuXAT DCX - AI PDF Modifier

QuXAT DCX - AI PDF Modifier is a powerful tool designed to streamline document updates for hospitals and organizations.

## Features
- **PDF Ingestion**: Upload text-based PDFs.
- **Date Detection**: Automatically detects various date formats.
- **User Review**: Editable table to review and modify detected dates.
- **PDF Reconstruction**: Generates a new PDF with updated dates, preserving original layout.

## Requirements
- Python 3.8+

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Run the application:
   ```bash
   streamlit run app.py
   ```
2. Upload a PDF file.
3. Review detected dates and make changes.
4. Download the modified PDF.
